# 基本常用指令

學一些足以讓你在終端機裡生存的指令

### 搜尋類

- `ls`：列出目錄內容
- `cd`：切換目錄
- `mkdir`：建立新目錄
- `which`：查找指令的路徑
- `cat`：顯示檔案內容
- `exit`：退出終端機
- `top`：查看系統資源使用情況
- `clear`：清除終端機畫面
- `echo`：輸出文字到終端機
- `pwd`：顯示目前所在目錄
- `man`：查看指令的使用說明

### 操作類

- `rm`：刪除檔案或目錄
- `cp`：複製檔案或目錄
- `mv`：移動檔案或目錄
- `touch`：建立新檔案
